The manager requires the stable provider subject, a boolean `email_verified: true`, and matching raw/parsed email and subject. Only a missing linked identity permits lookup/creation; database errors stop login. Both automatic and explicit linking use the installed native helper's sixth (`retry`) argument to prevent its unlink-and-replace fallback, including concurrent attempts. Existing provider mappings cannot silently change. Providers without usable verified-email claims are refused rather than trusting an email string.

The controller checks userinfo against the ID-token subject, reports failed linking as a failure, and retains native session destruction. It no longer stores the provider ID token in the session or puts tokens in logout/link redirects. Logout affects this application, not the user's Google session. Passport's ten-argument verification callback is preserved because the library selects its callback form by arity.

Installation for the existing local instance: add read-only mounts for each `.mjs` file to its corresponding `/overleaf/services/web/modules/authentication/oidc/app/src/<filename>` path in Toolkit `config/docker-compose.override.yml`, preserving the existing browser timing mount. Recreate only the existing `sharelatex` service with `PULL_BEFORE_UPGRADE=false bin/up -d sharelatex` from `$HOME/overleaf-ws1/toolkit`, with GNU sed/coreutils/grep first on PATH. Match the image and original source hashes above before upgrading. Roll back by removing only these two mounts and recreating the same service; data and the browser timing override remain intact. Do not copy either file to an unrelated CE+ release without checking compatibility.

`google.env.example` is inactive and contains no credentials. Register a Google **web application** OAuth client and its exact callback URI, then fill the client ID and secret in private Toolkit configuration. Never put the client secret in this repository or chat. The local callback is for this Mac only; a shared deployment needs its own approved HTTPS URL and registered callback. Existing accounts/project permissions remain local. New Google identities need no application password. Fresh Google authentication needs internet; offline recovery after session expiry remains unfinished product work. Account linking needs an authenticated local session, and authenticated email alone must never replace a different provider subject.

Focused tests are archived as `test/oidc.test.mjs`; run `node --experimental-vm-modules --test test/oidc.test.mjs` in a temporary checkout. The installed-module smoke is `test/oidc-native-smoke.mjs`: copy it to `/tmp/overleaf-oidc-native-smoke.mjs` in the running sharelatex container, run `docker exec -w /overleaf/services/web sharelatex node /tmp/overleaf-oidc-native-smoke.mjs`, then remove that temporary container file. It stubs database/provider operations only within its own Node process and checks the actual installed native helper contract and Passport profile parser. The optional `test/oidc-local.browser.mjs` checks existing synthetic browser login/logout using the same private test environment variables as the free-account smoke. None of these checks establishes a real Google OAuth login.
