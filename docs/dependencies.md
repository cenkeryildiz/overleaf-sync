No new runtime package or service is introduced. Existing installed Passport OpenID Connect 0.1.2 and CE+ native helpers remain in use. Focused tests use Node’s built-in test/VM facilities; the existing browser tool runtime is not a shipped dependency.

The `runtime/fast-preview/` CE+ compile-manager/source-timing overlay retains AGPL-3.0-only terms and uses existing Redis/OT/PDF.js/compiler services. No new runtime package/service is introduced. The `runtime/texlive-course/` image adds 36 required TeX packages/dependencies and the required TeX Live infrastructure self-update; `packages.csv` records the exact installed revisions and individual licenses. The base image and original user data are preserved. Non-BMP support remains blocked by upstream editor/history validation, not silently accepted by these timing changes.

Browser recovery adds no installed package/service. It reuses native CodeMirror state 6.5.4/view 6.38.6/commands 6.10.1 (MIT; exact upstream tag licenses included in runtime/browser-recovery/CODEMIRROR-LICENSES.txt), the existing webpack runtime and browser localStorage/CacheStorage/Service Worker facilities. The wrapper and minimal CE+ source hooks are AGPL-3.0-only. Public asset digests, source provenance, per-profile privacy and rollback are documented in that directory. No private source/authenticated HTML is in its cache or build context.

Native pdfLaTeX uses official pdftex.aarch64-linux revision 78082 and required digest-pinned Ubuntu ARM libc, libcrypt and native Perl files/modules (original copyright notices retained; Perl interpreter hash checked), reusing installed TeX packages. The SyncTeX selection overlay is AGPL-3.0-only and uses native CodeMirror/Lezer math nodes and PDF.js. No npm dependency or service is added; exact platform/hash/rollback limits are in runtime/native-tex and runtime/synctex-selection.

Local recovery comparison reuses unchanged jsdiff 5.2.2 dist/diff.min.js from the pinned CE+ image cache (BSD-3-Clause, Kevin Decker; full notice in runtime/browser-recovery/DIFF-LICENSE.txt). Browser bundle SHA-256 77b1109f55e598cb607314ed61a4126dab3938a60c6307d9be194834aa356cbd; 17,530 bytes; no new npm install/service. Native browser APIs supply storage/rendering but no text diff. On-demand line comparison uses the library timeout/edit budget and an input cap; no automatic merge or new editor engine.

Incremental compiler trials are not shipped dependencies. `test/incremental-tex/` retains the TeXpresso frame-export patch against MIT-licensed upstream e8df7709077b2f86f6e16e6c86ceefb86de06f8d and its license, isolated Docker recipes and a source-free diagnostic driver. The isolated TeXpresso build uses SDL2 and MuPDF (including MuPDF's AGPL obligations); no binary is distributed. Official realtime-tex 0.0.7 ARM release checksums were verified. Its MIT VS Code host d9adbaac95c76afe46e20cc59eb75be09e632719 was inspected but is not incorporated. Neither engine nor the prototype npm tools are installed in the application. The plan records why neither replacement passed the actual-project requirements.
