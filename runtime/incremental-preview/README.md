# Unfinished incremental-preview candidate — disabled

This is preserved work in progress, not a working or accepted fast-preview feature. The local native pdfTeX path remains authoritative. The prototype combines TeXpresso/MuPDF live page frames with the unchanged batch PDF compiler. The earlier engine-only changed-page result was 31–32 ms but omitted the bitmap math font. The new Type3 resource loader, browser integration and Rust process boundary have not passed application qualification.

The first installed browser check returned HTTP 503 and no live page was qualified. The cause remains unresolved. An initial workspace-ownership hypothesis was disproved: the actual www-data Node process can create/remove a private workspace despite displayed root-owned 0755 metadata. Identify the exact snapshot/worker/sandbox failure with sanitized diagnostics before changing permissions. The worker's separate-UID/process-limit behavior also needs verification for the actual unprivileged service user. Do not expose/enable this candidate for shared testing until resource isolation, exact font rendering, source/build identity, stale-frame handling, malformed-input/access checks and actual browser latency pass. Its client defaults off; the stable collaboration deployment excludes its client/route/image overlays.
