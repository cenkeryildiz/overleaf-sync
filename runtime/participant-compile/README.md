# Participant compilation (unfinished opt-in integration)

GitHub delivers public compiler/application assets; authorized project members contribute browser WebWorkers. The existing CE+ server still handles identity, project storage, collaboration and metadata leases. This is not a standalone GitHub Pages application and does not yet remove the Mac dependency for collaboration. No public deployment is configured.

The opt-in URL is `?participant-compile=1`. Its bootstrap replaces the editor's normal compile request with a project-scoped participant job. It never falls back to server TeX. Other URLs retain the existing demo. One tab contributes one worker for its current project; collaborators can receive each other's compile snapshots, so outsiders cannot safely supply private-project compute.

Preserve its license and the archive's TeX distribution notices; the wrapper's AGPL license does not replace individual TeX/font licenses. Do not put the archive, private sources or runtime credentials in Git.

The browser has a project-only virtual filesystem, no native filesystem grant, disabled shell escape and shell scripts, and a fixed public asset network allowlist. The Rust stdio coordinator receives metadata only: bounded FIFO queue, one lease per worker, 30s renewable leases, 45s worker expiry, three attempts, exact result digests and superseded-generation refusal. Native membership/CSRF checks precede each claim, snapshot or upload. Uploads are binary PDF+gzip SyncTeX, bounded to24MiB; navigation is normalized only to known snapshot paths. Artifacts use immutable build directories and never overwrite source or a previous valid PDF.

Build from repository root: `docker build -f runtime/participant-compile/Dockerfile -t overleafcep-local/sharelatex-participant:20261116 .`. `apply.mjs` pins native router/editor/main hashes and refuses a different upstream version. Browser runtime files are mounted read-only under `/overleaf/services/web/public/participant`; private project snapshots are not static files. The runtime provisioning and exact integration check commands are recorded in the authoritative project plan. Rollback restores the saved compose override and recreates only sharelatex, retaining all data and original mounts.

Synthetic Chrome checks passed for multi-file pdfLaTeX, Latin Modern text/page geometry, math/TikZ/BibTeX, exact source, PDF export, both SyncTeX directions, repeat/reload, missing-package failure retaining the previous PDF, Stop/retry, five-user repeated jobs, cross-user assignment, injected worker termination/reassignment, and denied nonmember/revoked/duplicate results. The user reported physical-device compilation and other behavior worked, with typing-caret lag under review. The plan records measured latency, downloads and remaining acceptance gaps. These results do not qualify arbitrary documents, XeLaTeX/LuaLaTeX, every font, Safari/Windows, offline compilation, independent hosting or backup/restore.

For independently hosted participant-only deployment, set `participantCompilationOnly: true` in the existing private server settings and install the guarded `runtime/fast-preview/CompileManager.mjs`. The shared compile root rejects central TeX requests, including linked-project output compilation, before reading projects or contacting the compiler. The retained private demo deliberately keeps its native baseline available; this policy is not enabled there. No app container gets a Docker socket or a contributor's home-folder mount. Server-side SyncTeX queries use only the accepted immutable output build.

Participant results are supplied by trusted collaborators: hashes bind identity, not proof that a malicious collaborator executed TeX honestly. Do not enable for untrusted contributors or publish until the project release gates pass. Pinned SDK cancellation modifications are in `sdk-patch.mjs`; `test/participant-sdk.mjs` exercises cancellation/crash/success using the unmodified pinned SDK as input. Worker network requests are limited to the provisioned public asset list. Public compiler files must preserve upstream TeX/font notices and must not contain private sources or credentials.
